# Kontratar: AI-Powered Government Contracting Platform

Kontratar is a comprehensive, AI-powered platform designed to revolutionize how businesses approach government contracting. It integrates cutting-edge technologies across three major segments - a robust **Spring Boot microservices backend**, an intelligent **Python AI Service**, and a modern **Next.js frontend** - to deliver automated proposal generation, intelligent opportunity matching, and streamlined contract management.

---

## Platform Architecture

### 1. Backend Services (Java/Spring Boot Microservices)

The backend infrastructure consists of 10+ independent microservices built with **Spring Boot**, providing a scalable and maintainable foundation for the entire platform.

#### Core Microservices

- **API Gateway**: Public REST entry point with intelligent routing, authentication forwarding, and load balancing
- **Authentication Service**: JWT-based identity management, tenant administration, and role-based access control
- **Opportunity Controller**: UI-facing endpoints for browsing and filtering government contract opportunities
- **Opportunity Ranking Service**: AI-powered matching engine using cosine similarity and embeddings to score company-opportunity fit
- **Informational Service**: Proposal job management, simulation APIs, and business intelligence endpoints
- **API Orchestration Service**: Complex queries spanning multiple data stores with intelligent result aggregation

#### Data Ingestion Services

- **SAM Data Feed**: Real-time ingestion from SAM.gov with automated updates every 15 minutes
- **SIBR Data Feed**: Small Business Innovation Research (SIBIR) opportunity ingestion and normalization
- **USA Spend Data Feed**: Federal spending data ingestion for market analysis
- **SAM To Repository**: Data transformation and normalization pipeline
- **Award To Repository**: Contract award data processing and storage

#### Key Technologies

- **Framework**: Spring Boot 2.7+ with Spring Cloud ecosystem
- **Database**: PostgreSQL with multiple schemas (kontratar_main, kontratar_global, opportunity)
- **ORM**: Hibernate/JPA with custom query optimization
- **Security**: Spring Security with JWT authentication
- **API**: RESTful APIs with OpenAPI/Swagger documentation
- **Messaging**: Kafka for event-driven architecture
- **Caching**: Redis for high-performance data caching
- **Monitoring**: Spring Actuator with Prometheus metrics

### 2. AI Service (Python/FastAPI)

The AI Service is the brain of Kontratar, powered by **FastAPI** and advanced machine learning models to automate proposal generation and provide intelligent assistance.

#### Core AI Capabilities

**Proposal Generation Engine**
- **Automated Outline Generation**: Creates comprehensive proposal structures based on RFP requirements
- **Draft Generation Agent**: LangGraph-based agent with multi-step reasoning for content creation
- **Compliance Checking**: Automated validation against RFP requirements and formatting standards
- **Section Writing**: Context-aware section generation with company-specific customization

**Vector Search & Embeddings**
- **Qdrant Integration**: High-performance vector database with 40% faster search than ChromaDB
- **Semantic Search**: Find relevant past proposals, company documents, and opportunity matches
- **Document Embeddings**: E5-Large-v2 and Gemini embeddings for accurate similarity matching
- **Collection Management**: Tenant-specific collections with automatic scaling

**LLM Integration**
- **Multiple Providers**: Support for OpenAI GPT-4, Google Gemini, and local Ollama models
- **Fallback Strategies**: Automatic provider switching on failure for 99.9% uptime
- **Token Management**: Intelligent context window management supporting 512k+ tokens
- **Cost Optimization**: Provider selection based on task complexity and budget

**Automated Schedulers**
- **Proposal Scheduler**: Processes proposal generation queue every 30 seconds
- **Outline Scheduler**: Generates proposal outlines from opportunity data
- **Custom Opportunities Scheduler**: Handles user-uploaded opportunity processing
- **Past Performance Scheduler**: Aggregates and indexes past performance data
- **Simulation Scheduler**: Runs business development simulations
- **SAM Opportunities Scheduler**: Automated opportunity enrichment and matching

#### Key Technologies

- **Framework**: FastAPI with async/await for maximum performance
- **AI/ML**: LangChain, LangGraph, OpenAI, Google Gemini, Ollama
- **Vector DB**: Qdrant with quantized vectors and optimized indexing
- **Database**: Async SQLAlchemy with PostgreSQL
- **Scheduler**: APScheduler with distributed locking
- **Search**: Elasticsearch for full-text search across opportunities
- **Logging**: Loguru for structured logging and debugging

## Integration & Workflow

### Data Flow

1. **Data Ingestion**: Federal opportunity data flows from SAM.gov, SIBR, and USAspending through dedicated data feed services
2. **Normalization**: Data is cleaned, transformed, and stored in PostgreSQL with optimized schemas
3. **AI Processing**: Opportunities are analyzed by the AI Service, generating embeddings and ranking scores
4. **User Matching**: Machine learning algorithms match opportunities to user profiles based on capabilities and past performance
5. **Proposal Generation**: When users select opportunities, AI Service generates tailored proposal outlines and drafts
6. **Collaboration**: Teams collaborate on proposals through the frontend with real-time updates
7. **Export & Submission**: Final proposals are exported in required formats for submission
